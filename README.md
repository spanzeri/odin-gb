# ODIN-GB

This is for-fun/learning GB emulator written in the [Odin programming language](https://odin-lang.org/).

It follows the [video tutorial playlist](https://www.youtube.com/watch?v=peM-ZnAF8-Y&list=PLUJgQvmd6X0E) from Drudgerist.

Note that the code has deviated in a few places (other than the obvious different programming language).

In particular, I have tried to match the **Detail timing pseudocode** from [GB: Complete Technical Reference](https://gekkio.fi/files/gb-docs/gbctr.pdf).

For non-cpu information, the go to reference was the phenomenal [Pan Docs](https://gbdev.io/pandocs/) site.

## ROM

The emulator is meant as a programming exercise and doesn't contain any copyrighted data (neither game nor boot ROMs).
